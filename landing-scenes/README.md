## 무엇인가

「길 위의 성지」 인스타그램 홍보용 **스크롤 랜딩페이지 · 릴스**에 쓸 장면 이미지다.
과제 2의 10초 광고가 "번아웃 → 만남 → 동행 → 도착"이었다면, 이쪽은
순례의 하루만 따라간다 — **출발 → 물을 건넘 → 도착**.

| 파일 | 장면 | 구도 |
| --- | --- | --- |
| `scene-01-forest-trail.png` | 아침 숲길, 출발 | 뒷모습, 멀리 능선 |
| `scene-02-stream-crossing.png` | 계곡 돌다리를 건너며 | 얼굴이 보이는 유일한 컷 |
| `scene-03-chapel-arrival.png` | 언덕 위 성당 도착 | 뒷모습, 하늘 여백 |

얼굴이 2번에만 보이는 것은 의도한 것이다. 출발은 뒷모습, 중간에 표정이 한 번 열리고,
도착에서 다시 물러난다. 짧은 영상에서 감정이 열렸다 닫히는 리듬이 생긴다.
3번은 성당 위 하늘을 비워 두었다 — **"나서보니, 이미 준비된 길이었습니다"** 와 로고 자리다.

## 과제 2에서 그대로 이어받은 것

`storyboard.md` 의 캐릭터·톤 규격을 바꾸지 않고 썼다.

```
A Korean woman in her early 50s, short bob-length hair, wearing glasses,
wearing a checked shirt and brown trekking pants, carrying a backpack,
cinematic still-cut realism, warm high-chroma tone, sRGB
```

과제 2에서 겪었던 **인물 일관성 문제**는 이번에 참조 이미지 방식으로 해결했다.
1번을 확정한 뒤 그것을 참조로 넣고 `Keep the exact same woman from the reference image`
로 시작해 2·3번을 뽑았더니 단발·안경·체크셔츠·배낭이 세 장 내내 유지됐다.
과제 2 때는 시드 지정이 안 되어 프롬프트 고정으로만 버텼는데, 참조 이미지 쪽이 훨씬 안정적이다.

## 과제 2에서 바꾼 것 — 배경

원본 스토리보드는 배경이 **예루살렘**이었다(`Jerusalem stone walls`, `sunset over Jerusalem`).
10초 광고에서 순례의 원형 이미지로는 통했지만, 실제 서비스가 다루는 것은
**한국 가톨릭 성지 208곳**이다. 랜딩페이지에서 예루살렘을 보여주면 서비스와 어긋나므로
한국 산길·계곡·시골 성당으로 다시 잡았다.

(가) 겨울 마른 나무·새벽 안개 탓에 쓸쓸한 그림이 되었고,
(나) 인물이 어린아이처럼 나왔다. 과제 2에서 이미 확정해 둔
`cinematic still-cut realism` 과 순례자 규격을 처음부터 적용했어야 했다.
**기존 규격 문서를 먼저 확인하는 것이 새로 만드는 것보다 빠르다.**
