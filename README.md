# 길 위의 성지 (VisitHolyKorea) — 멀티모달 AI 광고 캠페인

> 코디세이 2026 AI 네이티브 과정 · 과제 2 (GenAI 기초 2 — 멀티모달 콘텐츠 제작)
> 제작: 노희선

---

## 1. 프로젝트 소개

가톨릭 성지순례 플랫폼 **"길 위의 성지(VisitHolyKorea)"**의 브랜드 인지 광고를
멀티모달 생성형 AI만으로 제작한 프로젝트입니다. 지친 일상 → 미카엘 천사와의 만남 →
동행 → 도착(브랜드 각인)으로 이어지는 10초 분량의 SNS 숏폼 광고를 기획부터 제작까지
전 과정 스스로 설계했습니다.

- **핵심 메시지**: "나서보니, 이미 준비된 길이었습니다"
- **영상 길이**: 10초
- **비율**: 16:9(유튜브용) + 9:16(숏폼용) 2종 제작 (보너스 3 달성)
